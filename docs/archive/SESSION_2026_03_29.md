## Plan aprobado

Ver detalle completo en `docs/PLAN_V1.3.0.md`.

### v1.3.0 — Derivación handoff (#16 + #17 + #26)
- Chat web en admin con WebSocket para que el fisio responda al paciente en tiempo real
- WA bridge: el fisio responde desde su WA personal con prefijos `1.`, `2.` por paciente
- Bot anuncia "Te paso con el fisio", fisio escribe libre (sin prefijo automático)
- Timeout configurable/tenant (default 1h) + `/bot` para devolver control
- Notificaciones: email mejorado + sonido/push admin + WA personal via template Meta
- Alerta al fisio si cita cancelada a <24h (email + WA)
- `sender_name` = username del AdminUser
- Estimación: 5-7 días

### v1.5.0 — Sesiones grupales (#18)
- Clases recurrentes + excepciones configurables desde admin
- Mismo intent `agendar_cita`, huecos grupales aparecen mezclados con individuales
- Las horas grupales son una cita más (sin desbloqueo, sin preguntar)
- Slots llenos NO aparecen
- Inscripciones en BD + Google Calendar (asistente)
- Cancelación = misma mecánica que individual
- Estimación: 3-4 días
